# Visual direction

Operate mode. White and warm light-gray work surfaces; charcoal top bar/sidebar; restrained State Farm-inspired red for actions, selection and urgency; green for verified assistance; amber for pending work. Rounded shadcn controls, readable sans-serif text, tabular numbers, generous map space and compact resource strip. Reference imagery is authority; this is a synthetic training app, with no implication of State Farm affiliation.

Creator: practical exercise setup beside a town preview. Respond: navigation, resources, Canvas town, household inspector, unit strip and recent events. Results: five computed metrics, comparison table, time series, final response map and household timeline. Every status uses text/icon plus color. Accessible HTML selection parallels Canvas selection. No external fonts/assets at runtime.
