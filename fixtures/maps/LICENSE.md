# Dallas street database

The OpenStreetMap-derived database in `dallas-streets-v1.json` is made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). © OpenStreetMap contributors. See [OpenStreetMap copyright](https://www.openstreetmap.org/copyright).

This database includes selected street topology, geometry, names, access/direction tags and turn restrictions. The normalization, exclusions and synthetic placement metadata are documented in the sibling source manifest and `tools/import_dallas.py`. The application source license does not replace the database license. Homes, incidents, capacities and outcomes are fictional exercise data; they are not resident records.
